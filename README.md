# Figma-Inspired Portfolio

A responsive portfolio recreated from the supplied screenshot using only:

- HTML5
- CSS3
- Vanilla JavaScript
- Lucide icons
- Google Fonts

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

1. Change your name and intro in `index.html`.
2. Replace the social links (`#`) with your GitHub/LinkedIn URLs.
3. Replace `your-email@example.com` with your email.
4. Update the experience cards.
5. Replace the two CSS-generated project mockups with screenshots of your real projects if desired.

The layout is intentionally close to the supplied design: dark purple background, glowing elements, compact navigation, two-column experience cards, central technology orbit, alternating project showcase and minimal contact/footer.
